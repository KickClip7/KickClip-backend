# RF-DETR checkpoint

The RF-DETR checkpoint is distributed separately and is intentionally excluded
from Git.

Place the file at:

```text
weights/rfdetr/checkpoint_best_regular.pth
```

Expected file metadata:

```text
Size:   127470159 bytes
SHA256: 5d1d05cf78b6a777430430955d0e745ce5c61913c659b2e96ae5deddbd1a3a94
```

The relative path is part of the frozen tracking runtime contract. Do not
rename or relocate the file without regenerating the frozen manifests.
